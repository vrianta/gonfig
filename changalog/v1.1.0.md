# Release v1.1.0

We're excited to release **v1.1.0** of `gonfig`! This update brings:

1. Full Pointer Support
2. Faster CLI Argument Processing
3. Safer Nested Struct Handling
4. Critical Bug Fixes for Private Struct Fields.
5. Automatic Help formating and argument support

---

## New Features

* **Full Pointer Field Support**: Struct fields using pointers (`*string`, `*int`, `*bool`, etc.) are now fully supported across `env`, `arg`, and `default` tags. The parser automatically allocates memory using `reflect.New` when needed.
* **O(1) CLI Argument Scanner**: Replaced repeated `os.Args` iterations with `ParseOSArgs()`. Flag parsing now runs once and caches results in a map, turning `lookupArg()` into a fast, constant-time lookup.
* **New Tag Added Description**: New tag added `dscription` which can used to print details of the variable.
* **Help Argument Support**: By mentioning the `-help\--help` details of the struct will be automatically printed.

---

## Improvements & Refactoring

* Added `CanAddr()` checks before recursing into nested structs to prevent reflection addressability panics.
* Enforced strict tag precedence (`env` > `arg` > `default`) using an early-exit `matched` state.
* Refactored help record accumulation to pass a pointer slice (`*[]help_record`) down recursive depth calls.
* Re-ordered field checks so unexported (`!CanSet()`) private fields throw clean errors immediately.
* Fixed string formatting in required field panic errors.
* Integrated recursive dereferencing for pointer types.
* Replaced string comparison for `time.Duration` detection with direct type matching against `reflect.TypeOf(time.Duration(0))`.

---

## Testing & Maintenance

* Added comprehensive test suites for pointer field populating (`TestParse_PointerFields`) and unexported private field rejection (`TestParse_PrivateFields`).
* Upgraded Go toolchain version to `1.24.3`.
